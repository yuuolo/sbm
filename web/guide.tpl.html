2导入订阅

一键导入 Shadowrocket
  1. 在 iPhone 上点「一键导入」，会自动打开 Shadowrocket 添加订阅。
  2. 没反应的话：点「复制订阅链接」，打开 Shadowrocket → 首页右上角 ＋ → 类型选 Subscribe → 在 URL 里粘贴 → 右上角「完成」。
  3. 在列表里点选一个节点，打开顶部的开关。第一次会提示添加 VPN 配置，选择「允许」。
一键导入 sing-box
  1. 点「一键导入」，在 sing-box 里确认导入。
  2. 没反应的话：复制订阅链接 → 打开 sing-box → 配置（Profiles） → 新建配置 → 类型选 远程（Remote） → 粘贴链接 → 打开「自动更新」→ 保存。
  3. 回到 仪表盘（Dashboard），选中这个配置，点 启用（Enable），允许添加 VPN。
  4. 在 分组（Groups） 里可以切换节点，例如在「🚀 节点选择」里固定某个节点。
一键导入 Clash Verge
  1. 先打开 Clash Verge Rev，再点「一键导入」，浏览器询问是否打开应用时选择允许。
  2. 没反应的话：复制订阅链接 → Clash Verge Rev 左侧 订阅 → 顶部输入框粘贴 → 点 导入。
  3. 点一下刚导入的订阅卡片，让它处于选中状态。
  4. 左侧 代理 页可以看到各个分组，默认已经设置好，一般不用改；想固定节点就在 🚀 节点选择 里选。
  5. 左侧 设置 → 打开 系统代理。部分软件不走系统代理时，可以改为打开 虚拟网卡模式（TUN）。
一键导入
  1. 点「一键导入」，在应用里确认。
  2. 没反应的话：复制订阅链接 → 配置 → 右下角 ＋ → URL → 粘贴链接 → 提交。
  3. 选中这个配置，回到首页点 启动，允许添加 VPN。
  4. 在 代理 页的 🚀 节点选择 分组里可以切换节点。
一键导入 Hiddify
  1. 点「一键导入」，在 Hiddify 里确认。
  2. 没反应的话：复制订阅链接 → 打开 Hiddify → 点 ＋（新建配置） → 从剪贴板添加。
  3. 点首页中间的大圆按钮连接；在 代理 页可以切换节点。

不同版本的客户端按钮名称可能略有差异，找意思相近的即可。

4连接与节点

订阅里包含以下节点：

导入后各个分组已经设置好，一般不用任何改动：

  • 🚀 节点选择：默认是 ♻️ 自动选择（自动用延迟最低的节点）。想固定用某个节点或某个地区，就在这里切换。
  • 🤖 AI 服务：ChatGPT、Claude、Gemini 等默认走美国节点，避免地区限制。
  • 📹 YouTube / 🎥 Netflix / 📲 Telegram：默认跟随节点选择，也可以单独指定节点。
  • Ⓜ️ 微软服务 / 🍎 苹果服务：默认直连，速度更快；个别功能打不开时可以切到节点选择。
  • 🛑 广告拦截：默认拦截常见广告域名；如果某个网站因此打不开，可以切换为直连。
  • 🎯 全球直连：国内网站和应用直连，不受影响。

Shadowrocket 使用 App 自带的分流规则，只需在首页选择节点。客户端会每隔一段时间自动更新订阅，管理员新增节点后你无需任何操作。

常见问题

导入失败，或订阅链接打不开

请确认链接复制完整（包括域名后面冒号和端口号）。如果打开显示 404，说明链接已失效（账号被停用或重置），请联系管理员获取新的使用说明页。

已经连接，但打不开网页

先在客户端里更新订阅，再换一个节点试试。仍然不行，请确认客户端是最新版本，或联系管理员。

怎么手动更新订阅？

Shadowrocket：首页下拉刷新，或左滑订阅点「更新」。sing-box：配置 → 选中配置 → 更新。Clash Verge Rev：订阅页点卡片上的刷新图标。Hiddify：首页配置名称旁的刷新按钮。

可以在多台设备上使用吗？

可以，你自己的手机、电脑都用这一个链接导入即可。请不要分享给其他人。

突然断开几秒后又恢复了？

管理员维护节点时会短暂断开，客户端会自动重连，正在进行的下载可能需要重试。
