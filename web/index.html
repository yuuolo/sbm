节点域名管理

一键部署节点时，会用所选主域名的 Cloudflare Token 添加 前缀.主域名 解析并申请证书。Token 只保存在订阅服务器上（仅 root 可读），保存后不会再显示。

主域名用途操作
添加域名
Token 创建方法（每个域名单独一个）：
  1. 域名的 DNS 需要托管在 Cloudflare（NS 已指向 Cloudflare）。
  2. Cloudflare → 右上角头像 → My Profile → API Tokens → Create Token → 选 Edit zone DNS 模板。
  3. Zone Resources 选 Include · Specific zone · 这个域名 → Continue → Create Token，复制生成的 Token。
保存前会验证：能否访问该域名、读取并编辑 DNS（会创建一条测试 TXT 记录并立即删除）。

更换 Token

验证通过后替换旧 Token。已签发证书的自动续期会直接使用新 Token。
